# 数据定义

FEFO仅分配到店后剩余有效期满足需求的库存；冻结量先扣，拆包需整包装，召回批不得调拨。

输入字段：record, kind, sku, lot, qty, frozen, pack, expiry, store, min_days, arrival, version, status。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

qty为库存件数或需求申请件数。frozen在stock行是冻结量，在demand行是门店已有可用量。库存先扣冻结，再按整包装向下取整；不能跨药品调拨。到期日当天不可用，剩余有效天数等于要求值时允许。缺口不自动改成零。截止日固定2026-11-18，便于复现。

## 批号合并与召回处置（M2）

同一药品+批号可由多张到货单（record）分别入仓，M2按(sku, lot)合并为一条批号台账，不再把后到来源整行隔离。台账列对平关系：到货量 = 已冻结 + 包装余数 + 可调拨量 + 停发量；可调拨量=(到货量-已冻结)按包装向下取整。合并批号保留全部来源单号（到货来源列）与各来源原始行号。M2的可调拨量是批号裁决口径（不判效期），已失效批号由M3按AS_OF剔除，最终可直接调拨量以M3为准，两个口径之差仅为到期批号数量。

同一到货单重跑（record+kind相同）：内容完全一致只计一次并计入重复数，绝不重复加量；内容不同按CONFLICT隔离且保留首条，不按文件顺序覆盖。同批号来源的包装或到期日不一致时按LOT_CONFLICT整批隔离，等待人工裁决。

召回采用**整批停发**策略：同批号任一到货单status=recall，该批号所有来源全部停发、可调拨量为0；召回凭证行以RECALL留存，同批正常来源以LOT_RECALL留存，原到货单与召回凭证均进入隔离清单与证据CSV，不丢失记录。台账同时给出“仅停来源备选可调拨”列（只剔除被召回到货单时本可释放的数量）与处置原因，说明取舍：仅停来源能保住其余货源，却可能让门店拿到同批风险货；整批停发更稳妥，代价是压住仍安全的库存。策略名称固定为“整批停发”，随每次结果输出。
